04 Recurring Issues

Hourly Activity (last 7 days)

RAM/CPU/Disk are the live % reading straight off Prometheus for that one component — a red-ringed point is at or above that reading's own red threshold. Everything else (Unreachable/Service/Backup) is a binary state with no percentage to show, so it plots how many distinct incidents were active that hour instead — a red-ringed point there is a statistical spike (that system's own count exceeds its mean + 2 standard deviations). One chart per system affected, grouped under its issue type, since a shared chart can't isolate one system's reading from every other affected system's line. Each system's own charts share one time-range control — drag across any one of them (or pinch to zoom on touch) and every other chart for that system zooms to the identical window, so metrics that moved together are easy to line up; the Range buttons above each system are the same control for keyboard/screen-reader use, and "Full" resets. This is a live drill-down on this page only — it never changes what's in the downloaded PDF or e-mail, which always show the full 7 days.
