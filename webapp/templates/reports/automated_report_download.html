Hourly Activity (30 days, showing the most recent 7)

RAM/CPU/Disk are the live % reading for that one component — a red-ringed point is at or above that reading's own red threshold. Everything else (Unreachable/ Service/Backup) is a binary state with no percentage to show, so it plots how many distinct incidents were active that hour instead — a red-ringed point there is a statistical spike (that system's own count exceeds its mean + 2 standard deviations). One chart per system affected, grouped under its issue type, since a shared chart can't isolate one system's reading from every other affected system's line. Each system's own charts share one time-range control — drag any one of them to scroll left/right, or scroll/pinch to zoom, and every other chart for that system follows along, so metrics that moved together are easy to line up; the Range buttons above each system are the same control for keyboard/screen-reader use. Every chart opens on the most recent 7 days — drag left (or click further back on the scrollbar under it) to reach the other 23 days behind it, all the way to the oldest point captured. This is a live drill-down on this page only — it never changes what's in the downloaded PDF or e-mail, which always show the most recent 7 days.
