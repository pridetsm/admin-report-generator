{% extends "base.html" %} {% block title %}Network Infrastructure SOD Report{% endblock %} {% comment %} The Start-of-Day checklist — the entry screen for the report the on-duty engineer signs each morning. Structurally this is the app's normal report screen (header card, stat pills, sections in cards, sticky action bar) so a network admin who has run the other two reports already knows how this one works. What differs is the direction the data flows: the other screens PRESENT what Prometheus captured and ask for comments, while this one ASKS for readings that live in four vendor consoles the app cannot query. So every field starts blank on purpose. A blank cell reaches the workbook as a blank, which says "not captured this morning" — a true statement. The only pre-filled rows are the ones network_sod.collect() could answer from the SNMP scrape, and they are marked as such so nobody re-keys them from the console. {% endcomment %} {% block body %}
