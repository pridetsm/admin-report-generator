RAM/CPU/Disk are the live % reading straight off Prometheus for that one component — a marked point is at or above that reading's own red threshold. Everything else (Unreachable/Service/Backup) is a binary state with no percentage to show, so it plots how many distinct incidents were active that hour instead — a marked point there is a statistical spike (that system's own count exceeds its mean + 2 standard deviations). One chart per system affected, grouped under its issue type, since a shared chart can't isolate one system's reading from every other affected system's line.
