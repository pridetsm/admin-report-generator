How many days old a host's newest backup may be and still count as current — the report reads each host's newest backup file against this on every capture. Almost every host backs up daily, so {{ default_days }} (today or yesterday) is the default for any host left blank here; a host on a slower cycle (e.g. a database whose full backup runs every 3rd day) needs its own number, otherwise the gap between its runs reads as a missing backup. Off days are a separate setting, for a host that simply doesn't run a backup on a given day of the week at all (not a slower fixed cycle like the 3-day example above) — tick a day and a check run the morning after it will not treat that gap as a missing backup. Every Save creates a new, permanent revision below — nothing is ever edited or deleted. Save only records the revision. Save & Apply also rewrites the live policy file — no service to restart, so it takes effect on the very next report.
