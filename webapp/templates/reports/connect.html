How this works

Connect opens a dialog with what you need to reach that host — the address and a paste-ready command, each with a copy button. Paste it into the Run box (Windows) or a terminal (Linux) and you're on.

It hands over a command rather than launching for you because a web page cannot start a program on your PC — that is the browser's security model, not a limitation here. Remote Desktop and ssh then ask for the credentials themselves, so saved credentials, smart cards and Windows Hello all keep working and nothing sensitive is ever typed into this page.

Live status comes from Prometheus, which sees the network from the server's position — not your desk. That is why a host that is "not reporting" is still clickable: the signal is a hint, never a gate.
